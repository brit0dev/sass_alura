# SASS Styling Project

This repository contains the projects developed during the **"SASS and CSS: Styling a Website"** course by **Alura**. The goal was to learn and apply the features of the SASS preprocessor to create more efficient, reusable, and maintainable stylesheets.

## Learned Skills

- **SASS installation and setup**: How to install and start the SASS compiler.
- **Nesting styles**: Organizing code in a hierarchical and intuitive way.
- **Variables, Partials, and Mixins**: Using variables to optimize code and creating reusable components with mixins and partials.
- **@extend and Parent Selector**: Reusing styles with @extend and customizing selectors with Parent Selector.
- **Variable scope and calculations**: Understanding variable scope and how to perform mathematical operations within SASS to create dynamic layouts.

## Main Aspects

- **Reusable code creation**: Using mixins and @extend to reuse styles efficiently.
- **Modularizing stylesheets**: Breaking down code into smaller, more manageable files with partials.
- **Using variables**: Making it easier to personalize themes and layout adjustments.
- **Calculations in SASS**: Performing mathematical operations to adjust the layout, such as calculating margins, padding, etc.
